SWETHA BIRTHDAY SURPRISE WEBSITE

FILES
- index.html
- style.css
- script.js
- server.js (optional local Node.js server)
- images/ (your five uploaded photos)

RUN LOCALLY
1. Open this folder in VS Code.
2. Open index.html with Live Server, OR run:
   node server.js
3. Visit http://localhost:5500/

GITHUB PAGES
1. Upload index.html, style.css, script.js, and the images folder to the repository root.
2. In GitHub: Settings > Pages.
3. Select the main branch and /(root), then Save.
4. Wait for the deployment link.

IMPORTANT
- The PIN remains 0307. Change SECRET_PIN in script.js if needed.
- Birthday countdown remains set to December 3, 2026.
- Background music expects music/song.mp3. Add your own licensed audio file there if you want music.
- All photo references now use portable relative paths, so they work after publishing.
